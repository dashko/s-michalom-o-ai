# Kedy lokál, kedy API, kedy hybrid

## Lokál dáva najväčší zmysel vtedy, keď

1. pracujete s citlivými dátami,
2. nechcete posielať interné dokumenty alebo firemný kontext do externého API,
3. máte opakovaný workload a model používate pravidelne,
4. chcete mať kontrolu nad verziou, správaním a prevádzkou,
5. chcete predvídateľnejšie náklady,
6. alebo chcete AI integrovať hlbšie do vlastných procesov.

Typicky to môže byť interná dokumentácia, firemný knowledge assistant, analýza zmlúv a reportov, coding asistent vo vlastnej infraštruktúre alebo opakované interné workflow, kde sa AI používa denne.

## API dáva najväčší zmysel vtedy, keď

1. chcete začať okamžite,
2. nechcete riešiť hardvér ani deployment,
3. potrebujete špičkový model bez kompromisov,
4. máte zatiaľ menší objem používania,
5. si chcete najprv overiť use-case bez investície do vlastnej infraštruktúry,
6. alebo potrebujete škálovať.

Pre veľa jednotlivcov a menších tímov je API stále najrozumnejší prvý krok.

## Veľmi často najlepšie funguje hybrid

- Rutinné a citlivé workloady bežia lokálne.
- Náročné alebo zriedkavé high-end úlohy idú cez API.

Takýto prístup vám dá kontrolu tam, kde ju potrebujete, nižší náklad pri opakovaných úlohách a zároveň prístup k top modelom tam, kde dávajú zmysel.

Ak by sme mali odporučiť jeden realistický enterprise prístup, veľmi často by to bol práve hybrid.
