# Praktické tipy pre lepšie prompty

Tieto tipy pomáhajú znížiť priestor na hádanie a zvýšiť kontrolu nad výstupom modelu.

## 1. Zmeňte rolu

```text
Odpovedz najprv ako implementátor. Potom ako audítor, ktorý hľadá riziká.
```

## 2. Povedzte, pre koho je odpoveď určená

```text
Prepíš to pre CEO v 5 vetách.
```

```text
Prepíš to pre juniora krok za krokom.
```

```text
Prepíš to pre QA ako checklist.
```

## 3. Nastavte tón, dĺžku a hĺbku

```text
Buď stručný, vecný a praktický. Bez teórie. Max 150 slov.
```

```text
Daj mi dve verzie: jednu ultra stručnú a jednu detailnejšiu.
```

## 4. Dajte výstupu šablónu

```text
Odpovedz v tabuľke so stĺpcami: problém, príčina, návrh, ďalší krok.
```

## 5. Povedzte aj to, čo nechcete

```text
Bez úvodu. Bez teórie. Neopakuj zadanie. Max 8 bodov.
```

```text
Nevymýšľaj údaje. Ak si nie si istý, označ to.
```

## 6. Dajte kontext a obmedzenia

```text
Kontext: pripravujem interné školenie.
Cieľ: chcem vysvetliť základy prompt engineeringu.
Obmedzenia: publikum sú začiatočníci, mám 15 minút, nechcem technický žargón.
```

## 7. Nech sa model najskôr spýta

```text
Skôr než odpovieš, polož mi maximálne 3 otázky, bez ktorých nemôžeš pokračovať.
```

## 8. Ukážte vzor

```text
Tu je vzor. Teraz sprav to isté pre môj prípad.
```

## 9. Dajte modelu kritériá úspechu

```text
Priority sú:
1. jednoduchosť,
2. spoľahlivosť,
3. nízka údržba,
4. až potom výkon.

Ak sú dve riešenia podobné, vyber to s menším rizikom.
```

## 10. Nech model rozmýšľa po krokoch

```text
Rozdeľ úlohu na 3 až 5 krokov.
Pri každom stručne povedz, čo ideš spraviť.
Potom daj finálnu odpoveď.
```

```text
Najprv priprav draft, potom krátku kritiku a potom finálnu verziu.
```

## 11. Nech model porovná alternatívy

```text
Navrhni 3 možnosti.
Pri každej uveď výhody, riziká a náročnosť.
Potom odporuč najlepšiu podľa kritérií: jednoduchosť, cena a spoľahlivosť.
```

## 12. Rozdeľte riešenie podľa času

```text
Rozdeľ riešenie na:
- čo spraviť hneď,
- čo spraviť v najbližších 3 mesiacoch,
- čo riešiť dlhodobo.
```

## 13. Vyžiadajte si kontrolu kvality

```text
Najprv priprav verziu 1.
Potom sprav krátky QA checklist:
- sú splnené všetky požiadavky?
- čo chýba?
- čo je neisté?
- kde si odpoveď protirečí?
Nakoniec priprav opravenú verziu 2.
```

## 14. Oddeľte fakty, predpoklady a veci na overenie

```text
Rozdeľ odpoveď na 3 časti:
1. isté fakty,
2. predpoklady,
3. veci, ktoré treba overiť.
```

## 15. Nech model nájde slabiny a opraví ich

```text
Nájdi 3 slabé miesta v odpovedi.
Pri každom vysvetli, prečo je to problém.
Potom priprav opravenú verziu.
```

## 16. Dajte odpoveď skontrolovať dvom rolám

```text
Reviewer A: nájdi slabiny a riziká.
Reviewer B: zhodnoť, či je riešenie praktické a realistické.
Potom sprav krátku syntézu.
```
