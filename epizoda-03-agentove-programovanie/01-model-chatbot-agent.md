# Model, chatbot a agent

Dobrý model sám o sebe ešte nie je agent. Agent nie je ani vtedy, keď má model prístup k nástrojom.

Agent je vtedy, keď riadi postup práce: sám plánuje, rozhoduje sa, vykonáva, kontroluje a iteruje.

## Schopnosti agenta

Schopnosti coding agenta zahŕňajú:

1. volanie nástrojov a skladanie workflow,
2. testovanie a úpravu kódu,
3. riešenie bugov, refaktoring, code review,
4. prácu s Gitom (branch, commit, diff, PR workflow),
5. prácu s command-line,
6. pripojenie na databázy, dotazovanie a validácie.

Agent teda dokáže prejsť celým vývojovým cyklom, od návrhu cez implementáciu až po deploy.

## S akým modelom začať

Keď začínate s agentovým programovaním, odporúčame začať s rýchlejším a slabším modelom. Získate tak cit pre to, čo agenti dokážu a aké sú ich limity, a budete vedieť, čo od nich môžete očakávať. To je extrémne dôležité. Postupne môžete prechádzať na väčšie modely.

Tak ako na malú záhradu nebudeme brať traktor, nebudeme používať veľký model na písanie jednoduchých zmien.
