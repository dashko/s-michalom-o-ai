# Epizóda 00: Úvod do série

Táto epizóda predstavuje sériu od spoločnosti MSG o praktickom a bezpečnom používaní AI modelov a AI agentov.

Video: [Úvod do série](https://www.youtube.com/watch?v=0YwQXoS6Kpw)

## O čom je úvodná epizóda

Pri AI agentoch neriešime iba to, čo model odpovie. Riešime aj to, čo agent môže vykonať.

Úvodná epizóda vysvetľuje, prečo je pri agentoch dôležité myslieť na:

- limity jazykových modelov,
- súkromie a tok dát,
- bezpečnosť systému okolo modelu,
- kontrolované nástroje a obmedzené oprávnenia,
- rozdiel medzi rýchlym prototypovaním a robustnejším agentovým programovaním.

## Hlavná myšlienka

Najväčší problém pri AI agentoch nemusí byť inteligencia modelu, ale nekontrolovaný prístup.

Ak má agent prístup k nástrojom, súborom alebo systémom, potrebujeme jasne určiť, čo môže robiť, za akých podmienok a ako jeho správanie overujeme.

## Témy série

V ďalších častiach sa séria postupne venuje témam ako:

- prompt engineering,
- lokálne modely,
- agentové programovanie,
- MCP server,
- PydanticAI vrstva,
- RAG,
- tréningové dáta,
- fine-tuning.
